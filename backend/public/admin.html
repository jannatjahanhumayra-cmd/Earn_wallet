The current backend stores four slots (Top, Middle, Bottom, Gate) as HTML; it does not yet store separate network credentials, priority, reward rules or provider-level enable switches. Never paste bot tokens, private keys or account secrets here. Banner code is the safest fit for these iframe placements; Popunder / Social Bar / Smartlink behavior depends on each provider's terms and may not work inside an iframe.
